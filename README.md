# Machine Learning-Based Corporate Credit Scoring
This repository contains the Python source code, processed dataset, and supplementary materials used in the master's dissertation "Machine Learning-Based Corporate Credit Scoring".
The project evaluates Ordered Logistic Regression and Classification and Regression Trees (CART) for predicting corporate credit ratings using financial statement information and S&P credit ratings.

## Repository Contents
- Python script for data preprocessing
- Ordered Logistic Regression implementation
- CART classification model
- Model evaluation procedures
- Processed research dataset
## Reproducibility
All materials required to reproduce the empirical results presented in the dissertation are included in this repository.
